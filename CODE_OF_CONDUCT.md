# Code of Conduct

WPShield follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive, inclusive, and focused on defensive security. Maintainers may remove content that exposes private information, encourages abuse, or harms the safety of contributors or users.

The complete Contributor Covenant 2.1 text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/
