# NETworkManager and the WPShield operator experience

NETworkManager gives a Windows operator several ways to answer a network question from one application. This review examined the project's own documentation at revision `735173c` on November 22, 2026. The observations below describe documented behavior. A live comparison on Windows Server remains outside this review. [Upstream revision](https://github.com/BornToBeRoot/NETworkManager/tree/735173c0e1d40dafe76dcc4559e75b0e213d2e5b)

## Three ideas in delivery order

| Priority | Observed in NETworkManager | Proposed WPShield delivery and acceptance test |
| --- | --- | --- |
| 1. Find the right task | The Connections guide connects a question to a named view, its run command and its collection limits. It explains that a TCP snapshot can miss a short connection. [Connections guide](https://github.com/BornToBeRoot/NETworkManager/blob/735173c0e1d40dafe76dcc4559e75b0e213d2e5b/Website/docs/application/connections.md) | Give the README and bilingual landing page three entry points so an operator can inspect an IIS-hosted site, observe inbound and outbound traffic, or verify a login. At a 360 px viewport and with a keyboard, an evaluator should reach a working command and its prerequisites for each task. A synthetic example should show when attribution stays `unknown`. |
| 2. Inspect a traffic interval | The Network Interface view plots adapter upload and download rates. It labels units, allows inspection of historical samples and offers a return to the live view. [Network Interface guide](https://github.com/BornToBeRoot/NETworkManager/blob/735173c0e1d40dafe76dcc4559e75b0e213d2e5b/Website/docs/application/network-interface.md) | For the planned local dashboard, chart **observed IP bytes per second** within the selected capture scope. Use bounded interval counters before flow expiry, because summing the current rows loses bytes as flows leave the table. A synthetic trace with distinct inbound and outbound bursts, an expired flow and a capture gap should show the correct rates, an explicit gap and the UTC interval. Keep capture running when the operator pauses the view. [WPShield flow semantics](network-sensor-design.md#host-flow-view) |
| 3. Take a finding back to its source | The Connections view supports copying selected information and exporting selected rows. [Connections guide](https://github.com/BornToBeRoot/NETworkManager/blob/735173c0e1d40dafe76dcc4559e75b0e213d2e5b/Website/docs/application/connections.md) | Give a selected login record a copyable reference containing only the channel, provider, UTC time and record ID. With two services visible, keyboard selection must copy exactly one reference. A SQL login with unknown flow attribution must retain that state in the detail view. Test the same operation in English and Spanish. [WPShield audit evidence](network-sensor-design.md#sql-server-login-evidence) |

The first idea fits the public documentation. The latter two are proposals for M5's loopback dashboard and can use WPShield's existing local data sources. The upstream repository publishes the GNU GPL version 3 text. These proposals call for independent work using WPShield's own copy, examples and interface components.
